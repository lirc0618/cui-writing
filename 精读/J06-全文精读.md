# J06 全文精读

*Design of Optimal Scan Tree Based on Compact Test Patterns for Test Time Reduction*，13页；Linfeng Chen、Aijiao Cui（通讯）、Chip-Hong Chang合著。2026-10-21实际读完全部页块，B为原JSON零基编号。P3/P4/P5/P8实际原页核对，纠正抽取中补图上划线、λ、ω、Q′及集合/不等号乱码的阅读；其余页不标视觉完成。

## 全页段覆盖

- P1B0–B10、P2B0–B2：摘要先定失败条件“highly compact / few don’t cares”，概率图着色模型识别edges-per-vertex瓶颈，再导出inverse/aggressive关系、Q′连接与双模式保故障覆盖，最后报相同测试集的平均结果。引言从full scan可控可观与串行测试贵切入，区别test time、data volume、ATE带宽、解压器硬件/功耗/同步代价；don’t care被其他优化占用是更实际的缺口。
- P2B3–B9、P3B0：related work逐项承认hybrid/folding/插反相器及修改test vectors的作用，再限定非紧凑集依赖；[24]近似兼容改善树深但需线性模式补故障，多个scan tree还要额外输入/MISR。目标不是一味最浅，而是compact test set下保持fault coverage。
- P3B1–B15：七FF/四向量的完整例先解释兼容组、root/leaves、35→20 cycles；再把FF映为图顶点，兼容边及补图着色映射到树深，给clique/independent set与Turán关系。不同图的上划线在JSON丢失，原页已核对其功能。
- P4B0–B95：从Turán建立树深下界与e/n；假定n细胞/m完全指定向量，按匹配概率λ建边期望，兼容指数衰减；近似关系用HD权重并逐层抽取Gω、删除相关节点、条件概率和递推期望。公式不是独立装饰，而为为什么只按单一HD分组仍受限做准备。
- P5B0–B19、P6B0–B1：各子图色数下界求和；实测b19匹配率近λ0.5且窄分布，再对n500/1500、m50–230、λ0.4/0.5/0.6等计算ev/nv；0.8“安全上界”和0.38n依赖这些数值观察与模型，不直接升格成所有可能测试集的无条件定理。Figure3/4原页已看，支持桥到“提高e/n”设计目标。
- P6B2–B24：inverse compatibility来源注明已有BIST工作；AIC只在子图已抽取后加边，以固定顶点数提高边密度；AAC/AAIC用s扩展HD区间，最优s设计相关且NP-hard，后文只用启发式。Property1允许正/反关系，Property2要求适当取反后组内兼容，为电路可实现性约束。
- P7B0–B27：三顶点四种正/反组分布→任意三点应有0或2条AAIC边的条件→多点逐三点检查；DSATUR九步：构图、抽图、增边、补图、按饱和度/度选顶点、试最小颜色并验条件、重复、独色点放回再参与、终止。不是只增加任意边就能并行，三元符号一致性不能遗漏。

## 反向逻辑链与本轮新增限定

这是以Technique为主、针对fully specified compact setting重新分析旧方法边界的论文。缺口→模型瓶颈(e/n)→增加边但固定节点(AAC/AAIC)→符号一致性限制→双模式恢复覆盖→总测试时间/硬件与求解时间证据，链条较完整。文章不是把“more parallelism”自动当价值：树浅会增加补测试；AAIC可妨碍贪心后续；multiple chain更快但数据更多。标题“Optimal”必须在正文中还原成heuristic/local s search，不能给写作分身一个无条件全局最优证明模板。

尤其需要记住：0.8界与0.38n由模型和所计算范围支持；Q′连接省反相器有首层例外；fault coverage保持是双模式整体，不是tree模式本身；capture cycles被忽略；negligible overhead以MUX个数/FF数和单元大小作论据；16min是单次候选而非整个search；17例3个AAC-only更好属于本方法内的真实代价。

## 原句语言规律

“In this way, the number of vertices is maintained ... while more edges ...”把算法时序选择直接接回分析指标，值得迁移。“Though larger s ... it also increases ... Thus ...”连续三句把参数收益、代价、最终目标分开；“To highlight the dominant impact ... without considering AAIC”先讲消融目的；“However, it can be counterproductive sometimes”不隐去组合负效应；“It is inferred ... not likely ... supported by ...”区别模型推论与实证支持。原文“analysis has proved”与后面推断语气混用，应保留证据层次，不能只复制最强动词。

可迁移：从分析瓶颈推出机制、定义→性质→条件→算法→硬件→示例、多目标表格公平比较、用具体差例解释平均收益。不可复制：概率模型/图论界、AAC/AAIC判据、测试向量/故障结果、MUX及时间数字、对ATE存储磨损的普遍因果说法；本轮仅学习原文论证功能，没有技术复现。

未解决：不做概率独立假设/全局界及二分搜索适用性的独立数学审计，原文支持范围已明示；所有叙述页已读。
