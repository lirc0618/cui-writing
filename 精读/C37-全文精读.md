- P2B6–B7、P3B1：SoC复用/交易风险→constraint watermark→static检测昂贵/泄露grammar→FSM dynamic仍需STG/封装难检测→BIST可移除/partial-scan旧法受限→本文full/partial scan且看功耗。动机由检测链上的阻断逐层定位，非简单宏观意义；routing低开销有clustering与physical tool条件。
- P3B3–B4：先解释scan serial stimuli/response与位置关系，再定义π与Swm/S偶合率；明确单core/single chain仅用于例示，推广多core/multiple clusters为可扩展主张。7-cell/3-bit例在p2、p4、p7施约束，插入算法其余位置自由。
- P3B5–B7：给最终πwm、permuted WI′与WR′，抽4/2/7得101；原test vectors未产生同签名是例子观察，不能当任意test集合的零false-positive定理。水印vector需足够0/1以供约束选择。
- P3B9、P4B1–B2：owner secret key签MSG、one-way函数生成位置、R0/R1候选限制并移除allocated cell；伪码将OSC作为可替换优化器，体现框架/实例分层。公钥验证签名不自动隐藏位置，这个弱点后来C23明确修复，不能将两篇混成同一协议。
- P4B3–B7：power-driven OSC把完整test set bit differences写weighted graph，Hamiltonian/TSP难题后用NN greedy；p2例只从可输出0候选找最小edge。表明是启发式，非严格全局最优。算法‘constrained candidate set’正是后作识别的泄漏源。
- P4B9–B13、P5B1–B4：Pc先假balanced WR及位等概率，并含位置选择组合项；实验Mentor/MCNC、16/32/64/128bit随N选择。WTorg/WTmk是同OSC有无水印的weighted transition；最大<6%，不是相对任意实现都低于6%。
- P5B4–B5：Alice/Bob三类攻击，ghost靠one-way位置来源、removal靠test重建/route成本与长链隐藏位置、addition靠原水印残留及trusted timestamp。‘the reverse not true’是master先后包含关系；timestamp是外部信任条件。需保留‘supplements existing dynamic watermark’而非声称scan standalone不能去除。
- P5B6：结论回收封装后检测、specific position/verification sequence及power-order实例；‘test time and/or power’为框架可选优化目标，本篇验证power实例。P5B7–B10文献/授权信息全覆盖。
