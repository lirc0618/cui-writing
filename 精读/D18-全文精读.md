## 作者风格可迁移项

“受保护状态→合法迁移→寄存器物理采样”体现论证逐层深入。可学习的是用相同运行例对照正常/错误条件、再用统一符号说明故障入口；不能照搬原文对各种攻击/防护强弱的绝对判断。章节路标公开初版方案的jitter并提出有针对性的改进，优于只报两个孤立“新”方案。

paper-polish句例：P17“lead set uptime violations”应为“cause setup-time violations”；P20“all propriate state transitions”→“all legitimate state transitions”；P31“the next states does not belong”→“the next state does not belong”。若将P28的“State encoding cannot resist”改为“the illustrated encodings do not prevent the specified faulty transitions”，属于科学范围收窄，应说明并由当前稿作者确认。

不可进入分身事实库：被动段These FIA跳指、EDC零开销/extra bits冲突、one-hot重复终点、编号/姓名错配、对所有linear EDC和state encoding的泛化。学习结构与证据边界，不复刻错误。
